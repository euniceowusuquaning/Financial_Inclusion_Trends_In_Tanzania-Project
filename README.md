# Financial_Inclusion_Trends_In_Tanzania-Project
This dashboard, titled “Financial Inclusion Trends in Tanzania”, summarizes key insights about how people use mobile money, save, and participate in financial systems based on different demographics. Here’s what stands out:
1. Participants Overview
- Total participants: 7,092
- Gender split: 3,972 female (56%), 3,120 male (44%)

2. Mobile Money Usage
By Age Group:
- Young adults are the biggest users (3,734).
- Adults: 1,889
- Pensioners: 914
- Teenagers: 555    
*Insight: Mobile money adoption is highest among young adults.

By Gender:
- Female: 56%
- Male: 44%   
*Insight: Women slightly dominate mobile money usage.

Top Five Usage by Traders:
- Crop farmers lead (3,300)
- Non-traders: 2,710
Non-livestock traders, livestock traders, and agricultural traders follow with much smaller numbers.       
*Insight: Mobile money is strongly linked to farming activities.

3. Savings by Marital Status
- Married: 64%
- Single/never married: 17%
- Divorced: 10%
- Widowed: 9%   
*Insight: Married people save the most, possibly due to family responsibilities.

4. Education Levels
- Majority: Primary completed (3,446)
- Some primary: 1,046
- No formal education: 1,199
- University/higher: 708
- Some secondary: 467   
*Insight: Most users have basic education, which may affect how they interact with financial tools.

## Source  
The data used in this project is synthetic, aimed to be a representation of real-life data from kaggle.
